# Food Waste Management System

## Project Overview
The Food Waste Management System is a web-based application designed to reduce food wastage by connecting food donors with people in need. It allows donors to share available food, recipients to request food, and administrators to manage the platform efficiently.

## Objectives
- Reduce food wastage by encouraging food donations.
- Connect food donors with recipients.
- Simplify food donation and request management.
- Promote food sharing and community support.

## Technologies Used
- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **Backend:** Node.js, Express.js
- **Database:** MySQL
- **Authentication:** JSON Web Token (JWT)
- **Additional Technologies:** Socket.IO, Nodemailer, Leaflet Maps

## Features

### Donor
- Register and log in.
- Manage profile information.
- Add and manage food donations.
- View donation details and order status.
- Receive email notifications when food is ordered.

### Recipient
- Register and log in.
- Browse available food donations.
- Request and order available food.
- Track order details.

### Admin
- Manage users and donations.
- Monitor food donation activities.
- View dashboard statistics.
- Manage platform operations.

## Security
- JWT-based user authentication.
- Separate access for Donor, Recipient, and Admin roles.
- Secure API endpoints.

## Additional Functionalities
- RESTful API integration.
- Email notifications using Nodemailer.
- Real-time communication using Socket.IO.
- Location display using Leaflet Maps.
- Automatic removal of available donations after 24 hours.
